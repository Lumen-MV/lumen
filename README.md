# Lumen

Ứng dụng web tự cài (self-hosted) cho một nhóm nhỏ. Chạy bằng Docker trên VPS của bạn, mỗi người tự cấu hình bằng
file `.env` riêng.

*Self-hosted web app for a small private group. Runs with Docker on your own server; all configuration lives in
your own `.env`. MIT licensed, shared as-is.*

## Bắt đầu

```bash
git clone https://github.com/Lumen-MV/lumen.git
cd lumen
```

Toàn bộ hướng dẫn (tính năng, yêu cầu, cài đặt, cấu hình) nằm trong thư mục `docs/` và `infra/` sau khi tải về:

- `docs/huong-dan.md` — giới thiệu, yêu cầu, cấu hình
- `infra/README-deploy-vi.md` — cài lên VPS từng bước
- `docs/dev-notes.md` — ghi chú kỹ thuật cho người muốn sửa code
